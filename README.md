## 📖 About

**Tanah Batak** is a cultural web platform that introduces the Batak people — one of the largest ethnic groups in Sumatra, Indonesia — through their history, traditions, tourism destinations, and ancestral heritage.

Built as a passion project to preserve and share cultural knowledge digitally, the site serves as an accessible entry point for both Batak descendants discovering their roots and travelers curious about North Sumatra's rich heritage.

---

## ✨ Features

- 🏛️ **Cultural heritage sections** — explore Batak traditions, rituals, and ancestral wisdom
- 📜 **Historical narratives** — timeline of the Batak civilization through generations
- 🏞️ **Tourism destinations** — curated guide to Lake Toba, Samosir, and other heritage sites
- 🎨 **Traditional arts & crafts** — showcase of ulos weaving, music, and folk art
- 📱 **Fully responsive** — optimized for mobile and desktop reading
- ⚡ **Fast page loads** — built with Next.js static generation

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ and npm
- Git

### Installation

```bash
# Clone the repository
git clone https://github.com/immanueltampubolon594/Tanah-Batak.git
cd Tanah-Batak

# Install dependencies for frontend
cd app/frontend
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
npm run start
```
